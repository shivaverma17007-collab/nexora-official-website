NEXORA currently runs as a web app. Open it first, then use your browser’s install or home-screen option if your device offers it.

Choose how to get NEXORA

The steps depend on your device and browser.

📱 Android

1Tap Open NEXORA below in Chrome.
2Open the browser menu (⋮) and look for Install app or Add to Home screen.
3Confirm the prompt if it appears.

🍎 iPhone & iPad

1Open NEXORA in Safari.
2Tap Share (the square with an upward arrow).
3Choose Add to Home Screen, then tap Add.

💻 Windows / Linux

1Open NEXORA in Chrome or Edge.
2Look for the install icon in the address bar, or open the browser menu and choose Install NEXORA / Install this site as an app if shown.

🖥️ Mac

1Open NEXORA in a supported browser such as Chrome or Edge.
2Use the browser’s install option if available. Safari users can use Add to Dock on supported macOS versions.

Important: These instructions do not create an App Store or Play Store download. An install prompt appears only when the existing app meets that browser’s PWA requirements. If you do not see an install option, you can still use NEXORA directly in your browser. The website cannot force-install an app on another domain.
